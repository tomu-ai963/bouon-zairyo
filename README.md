# 防音室 材料帳

部屋の寸法を入れると、防音室に必要な材料の数・重さ・値段と、床にかかる荷重の目安を計算するスマホ向けWebアプリです。

## できること

- 床の幅・奥行・天井の高さ・ドアの寸法から、材料の数を自動で計算
- 自動で出した数は後から手で直せる（「自動に戻す」で基準の数に戻る）
- 材料ごとに「数量・総重量（1個あたり）・金額（1個あたり）」を表示
- 値段や重さに幅がある材料は「最小〜最大」で表示
- 床の荷重を 180kg/m²（1,800N/m²）に対する割合で表示
- 入力内容はブラウザに自動保存。書き出し・読み込みでバックアップ可能

## 自動計算の前提

| 材料 | 計算の元 |
|---|---|
| 木材（間柱） | 間柱・上下の枠・天井の桟・ドア枠の長さ ÷ 3m、ロス10% |
| 石こうボード・遮音シート・グラスウール | 壁＋天井の面積 ÷ 1枚（1巻・1袋）の面積、ロス分を加算 |
| ベニヤ板 | ドアの両面の面積 |
| 吸音材（ホワイトキューオン） | 壁の3割に貼る想定 |
| 防振ゴム | 外周に720mm間隔 |
| ドア金物 | ドアの枚数分（蝶番は1枚につき3枚） |

1枚あたりの広さ、重ね枚数、ロス率は材料ごとに「内容を編集」から変更できます。

## 注意

- 床の荷重は、総重量を床面積で割った平均値です。壁の重さは部屋の外周に集中するため、実際の負担はこれより大きくなります。
- 設置できるかどうかは、マンションの管理規約や管理会社に確認してください。
- 値段は2026年9月時点のネット相場・手書きメモをもとにした目安です。

## 使い方

`index.html` をブラウザで開くだけで動きます。ビルドや外部サーバーは不要です。
